# sz3-feedstock

[![Build AMD64](https://github.com/hep-forge/sz3-feedstock/actions/workflows/autoupload.amd64.yml/badge.svg)](https://github.com/hep-forge/sz3-feedstock/actions/workflows/autoupload.amd64.yml)

Feedstock for [sz3](https://github.com/szcompressor/SZ3) — part of [hep-forge](https://anaconda.org/hep-forge).

Error-bounded Lossy Data Compressor (for floating-point/integer datasets)

## Install

```bash
conda install -c hep-forge -c conda-forge sz3
```
