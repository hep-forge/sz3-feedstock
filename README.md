[![Anaconda Platforms](https://anaconda.org/hep-forge/sz3/badges/platforms.svg)](https://anaconda.org/hep-forge/sz3)

Feedstock for [sz3](https://github.com/szcompressor/SZ3) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Error-bounded Lossy Data Compressor (for floating-point/integer datasets)

## Architectures

| Architecture | Latest published |
|--------------|------------------|
| linux-amd64 (`linux-64`) | ✅ `3.3.1` |
| linux-arm64 (`linux-aarch64`) | ❌ not published |

_As of the last feedstock render; the badges above are live._


## Install

```bash
conda install -c hep-forge -c conda-forge sz3
```
